# AutoLoc

## Acteurs

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Cas d'utilisation

### Client
- Consulter les vehicules disponibles
- Reserver un vehicule
- Consulter ses reservations

### Agent d'agence
- Gerer les reservations
- Gerer les clients
- Gerer les vehicules

### Responsable d'agence
- Superviser les activites de l'agence
- Consulter les statistiques
- Gerer les agents

### Administrateur
- Gerer les utilisateurs
- Gerer les agences
- Administrer le systeme
